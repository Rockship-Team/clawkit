# Ebook Outline Template

Ebook = long-form content (3000-8000 words) dem lai authority + lead magnet (gated download → capture email).

## Cau truc 8 phan chuan

| # | Section | Length | Vai tro |
|---|---|---|---|
| 1 | **Tieu de + sub-title** | 1-2 line | Hook reader. Specific problem + benefit (vd "12 thang automate BD pipeline — SME B2B Viet Nam") |
| 2 | **Tom tat (1 page)** | 200-300 words | Reader doc 1 page biet co gi |
| 3 | **Ai nen doc + Khong nen doc** | 1/2 page | Filter audience, build trust |
| 4 | **Phan 1: Problem deep-dive** | 600-1000 words | Mo ta pain co data, vi du SME thuc te (lay tu CRM history neu enough) |
| 5 | **Phan 2: Framework / approach** | 800-1500 words | Method propose, 3-5 step framework, diagram |
| 6 | **Phan 3: Case study** | 800-1500 words | 1-3 case studies (anonymize neu can). So + lesson learned |
| 7 | **Phan 4: Action playbook** | 400-800 words | Checklist / template / next-step concret reader co the do ngay |
| 8 | **CTA + Footer** | 1/2 page | "Trao doi them: gui mail X" + link resource + author bio |

## Step write

1. **Outline (1h):** chot 8 section title + 3 bullet moi section
2. **Research (2-4h):** pull case study tu CRM (`sme-cli cosmo api POST /v1/contacts/search filter business_stage=WON`), gog search competitor blog, web search benchmark
3. **Draft (4-8h):** viet tung section, voice consistency (theo voice-guide.md)
4. **Edit + design (2-4h):** tao Google Doc (qua gog drive upload --convert-to doc), thuc nguoi review, design pdf (Canva)
5. **Distribute:** gate behind email form, push qua LinkedIn post + email blast

## Topic suggestion (pick 1)

- "12 thang automate BD pipeline cho SME B2B (case Rockship)"
- "AI for sales — 7 workflow co the trien khai trong 1 tuan"
- "Tu manual outreach 50/tuan toi 500/tuan tu dong — full setup"
- "Cold email reply rate 5% → 22% — A/B test 90 ngay"

## KHONG bao gio

- Ebook generic kieu "What is AI? History of AI" → nguoi doc ngu
- Khong co data thuc / case thuc → mat credibility
- Pdf 50 trang nhung 80% padding → reader bo
- Khong gate email → mat lead magnet value
