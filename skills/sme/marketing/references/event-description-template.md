# Event Description Template

Event description = noi dung mo ta event tren Luma / landing page / email invite. Goal: convince reader RSVP.

## Cau truc 6 phan

### 1. Tieu de event (max 80 chars)

Format: `[Action verb] [outcome] cho [audience]` hoac `[Topic] — [unique angle]`

Vi du:
- "AI Agent Workshop — setup BD bot tu A-Z trong 2h"
- "SME B2B Sales Mixer — 30 founder/CEO chia se pipeline"
- "Hands-on: Build cold email automation cuoi tuan nay"

### 2. Mo ta ngan (80-120 words) — first thing reader doc

Pattern:
- Cau 1: **What** (1 cau loai event + nhom dich)
- Cau 2-3: **Why** (pain point audience co the relate)
- Cau 4-5: **What you'll get** (3 outcome cu the)
- Cau cuoi: **Who's this for** (filter)

Example:
> Workshop hands-on 2 tieng cho SME founder/CEO + sales lead muon tu dong hoa BD pipeline.
> Neu anh/chi dang phai theo doi 50+ lead bang tay, gui follow-up khong dung luc, hay khong biet deal nao nen uu tien — workshop nay se dem lai:
> 1. Framework 4-step thiet ke BD bot phu hop scale cua minh
> 2. Tao bot demo trong 90 phut voi data thuc cua company
> 3. Playbook 30/60/90 ngay sau workshop
> 
> Phu hop voi: founder/CEO SME 5-50 nguoi, sales lead, COO. Khong yeu cau code.

### 3. Agenda (clear timeline)

```
14:00 — Mo dau + tu gioi thieu (15p)
14:15 — Phan 1: Tai sao BD bot khac CRM (15p)
14:30 — Hands-on: Setup bot dau tien (45p)
15:15 — Break + networking (15p)
15:30 — Phan 2: Pipeline rule + alert (20p)
15:50 — Q&A + 30/60/90 playbook (10p)
16:00 — Ket
```

### 4. Speaker / Host bio (50-80 words)

Pattern:
- Ten + title hien tai
- 1-2 line credentials cu the (KHONG vague "expert in X")
- 1 line context tai sao ho host event nay

Example:
> Anh Khoa — Founder Rockship. Da xay 4 BD bot cho team noi bo + 12 SME khach hang trong 2 nam qua. Workshop nay tong hop 18 thang trial-and-error.

### 5. Logistics (clear, no jargon)

```
📍 Dia diem: Rockship Office, 31 Le Thanh Ton, Q1 (hoac online Zoom — gui sau khi register)
📅 Thoi gian: Thu 5, 30/05/2026, 14:00-16:00 (UTC+7)
💰 Phi: Free (limited 30 cho)
🎯 Yeu cau: laptop + email rockship17.co@gmail.com (de provision bot demo)
☕ Co Coffee + snack
```

### 6. CTA + FAQ ngan

```
👉 Dang ky tai: https://lu.ma/<slug>
👉 Cau hoi: dm @akhoa2174 hoac mail rockship17.co@gmail.com

FAQ:
- "Em chua code bao gio co tham gia duoc khong?" → Co. Workshop khong yeu cau code.
- "Sau workshop em co support tiep khong?" → Co private channel cho attendee 30 ngay.
- "Co thu nghiem voi data company em duoc khong?" → Yes — anh/chi bring 1 use case cu the.
```

## Format 3 length

| Channel | Length | Cau truc |
|---|---|---|
| Luma full | 400-600 words | Toan bo 6 phan |
| LinkedIn post invite | 150-200 words | Hook + Why + 3 outcome + RSVP link |
| Email blast | 200-300 words | Subject hook + 1 paragraph why + agenda summary + RSVP CTA |
| Telegram group invite | 60-80 words | "Anh em CRM/sales — Rockship to chuc workshop X ngay Y, free 30 cho, RSVP {link}" |

## Voice rule (theo voice-guide chinh)

- Vietnamese 100%, casual nhung khong "kid lang"
- KHONG dung jargon "synergy", "leverage", "ecosystem"
- KHONG promise "guaranteed 10x revenue" hoac stat khong co source
- Speaker bio HONEST — khong inflate

## KHONG lam

- Tieu de generic ("Free workshop about AI") — quy bao loc
- Mo ta dai >800 words → nguoi doc bo
- Agenda mo ho ("Discussion, Q&A") → unclear value
- KHONG co RSVP deadline → urgency = 0
